The honest part

Our own forecasting model was no better than simply guessing “the market goes up.” MarketLens tells you so.

The app scores its model against the simplest guess on the same days, over almost four years of real prices, and shows the result side by side. A forecast is worth nothing until it has a record against the simplest guess.

Try it in five minutes

You need Python 3.13. Run these lines in a terminal, then open http://127.0.0.1:8080.

View the code on GitHub 
# get it
git clone https://github.com/esst-prog2/MarketLens.git
cd MarketLens
# install once
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
# run
.venv\Scripts\python app.py
# macOS or Linux: .venv/bin/python instead of .venv\Scripts\python
